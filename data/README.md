# Data files

No lexicon or human annotation data are included in this documentation package.

Add the verified complete inventory as `KanuriSentiLex_v1.0.csv` and the consent-compatible human reference as `KanuriSentiLex_human_gold_400.csv` when ready. These filenames are suggested release names, not existing datasets.

Preserve the exact experimental outputs. Reconcile their columns with the data dictionary before renaming fields. Record the configuration used for the final inventory, score ranges, threshold values, missing-value treatment, and encoding.

Release individual annotator judgments and confidence values only when permitted by consent and institutional requirements. Use pseudonymous annotator identifiers and exclude identifying information.
